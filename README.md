### 📌 Projeto em destaque

**Sistema Bancário**

API REST desenvolvida com Java e Spring Boot, utilizando JPA/Hibernate e MySQL.

O projeto simula operações bancárias e possui recursos como:

Cadastro e autenticação de usuários
Autenticação baseada em JWT
Criação e gerenciamento de contas
Saques e transferências
Validação de dados
DTOs para requisições e respostas
Tratamento global de exceções
Testes automatizados

O projeto continua em desenvolvimento e estou utilizando sua evolução como forma de aprofundar meus conhecimentos em backend e desenvolvimento de APIs.
